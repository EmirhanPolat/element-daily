Privacy policy

Six Star Uploader, last updated 25 November 2026.

What the tool is

Six Star Uploader is a private tool used only by the owner of the Element Daily YouTube channel. It runs on the owner's own computer and uses YouTube API Services.

Google data it accesses

  • Permission to upload videos to the owner's YouTube channel (youtube.upload).
  • Permission to read the owner's channel and video information, such as title and publishing status (youtube.readonly).

How the data is used

Only to upload the owner's videos, schedule them and check their status. It is not used for advertising, profiling or any other purpose.

Storage and sharing

The sign-in token is stored only on the owner's computer. No Google data is sold, shared with or transferred to anyone else. There are no analytics, cookies or trackers on this website added by the owner.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the computer deletes all stored data.
